# Capstone
Repository containing all of the scripts that were used to analyze geometry, material properties, and testing results during the BYU 2025-26 Capstone Project with Korry Electronics

## Prompt Given at the Beginning of Capstone
Korry Electronics, a global leader in aerospace cockpit interfaces, is seeking a complete redesign of the actuation module in its ABS0951 cockpit switch. The current multi-part mechanism is difficult to manufacture and costly to assemble. This Capstone project challenges students to simplify the design using compliant mechanism principles, reducing part count and improving reliability while meeting all aerospace-grade mechanical and environmental standards.

## Repository Layout

| Folder | Purpose |
|------|------|
| `run_examples.py` | Demonstrates how to run the analyses |
| `requirements.txt` | List of Python packages needed to run scripts (pip install -r requirements.txt) |
| `data/` | Material property inputs |
| `src/models/` | Core compliant mechanism equations |
| `src/howell/` | Tabulated constants from Howell's textbook |
| `src/materials/` | Material database utilities |
| `src/studies/` | Scripts used for design studies |
| `src/utils/` | General helper functions |
